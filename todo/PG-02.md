### Acceptance criteria

- [ ] The tree matches the structure above.
- [ ] Children are loaded lazily on expand, with a loading state; a node with no
      children shows an empty state rather than an infinite spinner.
- [ ] Every node opens an info view (CORE-01).
- [ ] Node counts/badges where cheap to compute; never at the cost of an
      expensive catalog scan on expand.
- [ ] Partitioned tables show their partitions nested and are visually
      distinguishable from plain tables.
- [ ] Verified against a database that exercises every node type.
