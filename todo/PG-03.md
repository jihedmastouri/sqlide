## PG-03 — Dim `information_schema` and system schemas

- **Status:** done
- **Depends on:** PG-02

### Acceptance criteria

- [x] `information_schema` is present in the tree, rendered with reduced opacity
      (and sorted after user schemas).
- [x] `pg_catalog` and other `pg_*` schemas are treated the same way.
- [x] A setting toggles system schemas hidden/shown entirely; default shown-dimmed.
- [x] Dimmed does not mean disabled — they expand and open like anything else.
- [x] Sidebar search skips system schemas unless the filter opts them in.
