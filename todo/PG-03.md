## PG-03 — Dim `information_schema` and system schemas

- **Status:** todo
- **Depends on:** PG-02

### Acceptance criteria

- [ ] `information_schema` is present in the tree, rendered with reduced opacity
      (and sorted after user schemas).
- [ ] `pg_catalog` and other `pg_*` schemas are treated the same way.
- [ ] A setting toggles system schemas hidden/shown entirely; default shown-dimmed.
- [ ] Dimmed does not mean disabled — they expand and open like anything else.
- [ ] Sidebar search skips system schemas unless the filter opts them in.
