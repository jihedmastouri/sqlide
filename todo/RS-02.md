## RS-02 — Research: improve the Table Creator

- **Status:** done — research complete, follow-ups filed

### Questions to answer

- Create vs alter: is this one UI with two modes, or two features?
- How do we preview and confirm the generated DDL before running it, and how do
  we handle destructive alters (type changes, drops, not-null on existing data)?
- Per-engine type pickers with sensible defaults, plus engine-specific options
  (PG: identity vs serial, generated columns, partitioning; MySQL: engine,
  charset/collation, auto_increment; SQLite: type affinity, WITHOUT ROWID, and
  the fact that ALTER is severely limited and may need a table rebuild).
- Constraints, indexes and FKs defined inline in the same dialog or separately?
- Templates / copy-structure-from-existing-table.
