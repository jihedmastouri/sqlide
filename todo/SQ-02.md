## SQ-02 — PRAGMA viewer and editor

- **Status:** todo

### Goal

Show the connection's PRAGMA settings and let the user change the safe ones.

### Acceptance criteria

- [ ] A Pragmas view per SQLite connection listing name, current value, default
      and a short description.
- [ ] Boolean pragmas (`foreign_keys`, `recursive_triggers`, `case_sensitive_like`
      …) are toggleable; enumerated ones (`journal_mode`, `synchronous`,
      `locking_mode`, `temp_store`, `auto_vacuum`) use a select; numeric ones
      (`cache_size`, `busy_timeout`, `page_size`, `mmap_size`) take input with
      validation.
- [ ] Read-only/informational pragmas (`integrity_check`, `page_count`,
      `freelist_count`, `compile_options`, `database_list`) are shown as
      read-only, with a run button for the check-style ones.
- [ ] Pragmas that only apply at connect time, or that rewrite the file
      (`page_size`, `auto_vacuum`, `journal_mode` to/from WAL), are labelled as
      such and warn before applying.
- [ ] Destructive or dangerous pragmas (`writable_schema`) are not exposed, or are
      hidden behind an explicit advanced toggle with a warning.
- [ ] Per-connection pragma defaults can be saved to config (CORE-13) and applied
      on every connect.
- [ ] Changing a pragma refreshes the displayed values from the database rather
      than assuming the write succeeded.
